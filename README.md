# Township Overview

Мод для Melvor Idle v1.3.1 (с дополнениями TotH, AoD и ItA), который делает экран города в Township удобнее.

- **Мультивыбор биомов.** Кнопка «Мультивыбор» над списком биомов. В этом режиме клик по биому добавляет его в выборку или убирает из неё, а справа показываются построенные здания всех выбранных биомов, сгруппированные по биомам. «Все» и «Сброс» выбирают все открытые биомы или очищают выборку.
- **Фильтр по ресурсу.** Иконки ресурсов в строке «Производит:». Можно выбрать несколько, тогда показываются здания, которые производят хотя бы один из них. Работает и в обычном режиме, и в мультивыборе.
- **Сломанные.** Кнопка оставляет только здания с эффективностью ниже 100%. На кнопке и на биомах слева показано число сломанных зданий. Починить можно прямо из карточки в режиме мультивыбора.

Настройки сохраняются отдельно для каждого персонажа.

## Локальная установка (Creator Toolkit)

1. Подпишись на [Creator Toolkit](https://mod.io/g/melvoridle/m/creator-toolkit): через Mod Manager в игре (поиск «Creator Toolkit») или на сайте mod.io. Перезапусти игру.
2. Открой Creator Toolkit одним из способов: вкладка в Mod Manager, кнопка-звёздочка на экране выбора персонажа или пункт в боковом меню.
3. Добавь локальный мод:
   - **Steam:** режим *Directory Link*, указать эту папку. Мод перепаковывается при каждой перезагрузке игры, `.modignore` исключает лишние файлы.
   - **Браузер:** режим *Modfile*. Нужно запаковать в zip `manifest.json`, `setup.mjs` и `styles.css` (в корень архива) и выбрать этот архив.
4. Перезагрузи игру.

> Локальный мод не сохраняет настройки (`characterStorage`), пока он не привязан к моду на mod.io и не установлен оттуда по подписке. Без этого мод работает, но выбор биомов и фильтров сбрасывается после перезагрузки.

## Файлы

- `manifest.json` — описание мода
- `setup.mjs` — вся логика
- `styles.css` — стили
