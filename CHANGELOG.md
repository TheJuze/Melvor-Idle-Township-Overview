# Changelog

## 1.1.0

- **New:** "Can build" filter shows only buildings you can build right now: requirements met, not maxed, and enough resources for at least one. The button shows how many there are across all unlocked biomes. The list updates as resources change and combines with the other filters.

---

- **Новое:** фильтр «Можно построить» оставляет только здания, которые можно построить прямо сейчас: требования выполнены, здание не на максимуме, ресурсов хватает хотя бы на одно. На кнопке показано, сколько таких зданий во всех открытых биомах. Список обновляется при изменении ресурсов и сочетается с остальными фильтрами.

## 1.0.0

First release.

- **Multi-select biomes.** One biome selected shows the normal game view. Two or more show the game's own building cards for all selected biomes, grouped by biome, with build and repair available directly. Each biome header has **Open biome** and **Repair all in biome** (with cost).
- **"Produces" filter:** population, happiness, education, storage, worship, fortification, soul storage or any resource. You can pick several at once.
- **Broken** filter, with a count on the button and on each biome.
- **Only available actions.** Cards show the build button, the repair button, both, or none.
- English and Russian interface, following the game language.

---

Первый выпуск.

- **Мультивыбор биомов.** Один выбранный биом показывает обычный интерфейс игры. Два и больше показывают стандартные карточки зданий всех выбранных биомов, сгруппированные по биомам; строить и чинить можно прямо оттуда. В заголовке каждого биома есть «Открыть биом» и «Починить все в биоме» со стоимостью.
- **Фильтр «Производит»:** население, счастье, образование, хранилище, поклонение, укрепление, хранилище душ или любой ресурс. Можно выбрать несколько сразу.
- **Фильтр «Сломанные»**, с числом на кнопке и на каждом биоме.
- **Только доступные действия.** На карточке кнопка стройки, кнопка ремонта, обе или ни одной.
- Интерфейс на английском и русском, по языку игры.
